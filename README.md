# Giacomo Cozzi — Academic Website

Source repository for [giacomocozzii.github.io](https://giacomocozzii.github.io), an academic homepage collecting research interests, publications and computational projects.

## Contents

- `index.html` — homepage, bibliography, research and project links
- `style.css` — responsive visual design
- `.nojekyll` — static-file GitHub Pages configuration

## Update

Edit `index.html` to add or change publications, editorial status and project links. The site is static and has no build dependencies.

## Projects

- [SpEl — Experimental Music Score Analysis](https://github.com/giacomocozzii/SpEl-Research)
- [SWFlow — Sliced-Wasserstein Flow](https://github.com/giacomocozzii/SWFlowCode)

## GitHub Pages

If the site is not live, open **Settings → Pages** and set **Deploy from a branch → main → /(root)**, then save.

Publication metadata should be periodically verified against publishers and preprint records.
